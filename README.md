# Cómo correr el proyecto

## Requisitos

- [Node.js](https://nodejs.org/) versión LTS y npm.
- Un celular con Android 12 o superior y la app [Expo Go](https://play.google.com/store/apps/details?id=host.exp.exponent) instalada.
- El celular y la computadora conectados a la misma red Wi-Fi.

## Instalación

```bash
git clone https://github.com/CollabSW/virtu.git
cd virtu
npm install
```

## Ejecución en Android con Expo Go

1. Inicia el servidor de desarrollo:

   ```bash
   npx expo start
   ```

2. Abre Expo Go en el celular y escanea el código QR que aparece en la terminal.

Si la red no permite la conexión entre ambos dispositivos, prueba con `npx expo start --tunnel`.

## Otros comandos

```bash
npm run lint    # revisa el código con ESLint
npm run format  # da formato al código con Prettier
```
